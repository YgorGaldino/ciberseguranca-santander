# Cibersegurança do Zero à Prática

Repositório com os laboratórios, anotações e projetos que desenvolvo durante o bootcamp **Santander - Cibersegurança do Zero à Prática**, da DIO.

## 🎯 Objetivo

Aprender, na prática, como proteger sistemas e dados contra ataques cibernéticos, identificar vulnerabilidades e responder a incidentes.

## 📚 Conteúdo do bootcamp

- Fundamentos de IA aplicada à segurança
- Linux
- Kali Linux
- Medusa
- Python

## 🗂️ Estrutura do repositório

| Pasta | O que tem dentro |
|-------|------------------|
| `01-fundamentos-ia/` | Anotações sobre IA e segurança |
| `02-linux/` | Comandos e laboratórios de Linux |
| `03-kali-linux/` | Laboratórios com Kali Linux |
| `04-python/` | Scripts e exercícios em Python |
| `anotacoes/` | Resumos e aprendizados gerais |
